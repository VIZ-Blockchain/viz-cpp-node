# Своя нода VIZ на Windows

Эта папка — всё, что нужно, чтобы поднять личную ноду мейннета на обычном Windows-компьютере и переключить на неё Forecaster или VIZ Wallet. Нода стартует не с полного переигрывания цепи, а со снапшота, который скачивает у доверенных нод — это минуты, а не дни.

## Что понадобится

- Windows 7 SP1 или новее, 64-битная (сборка статическая, ничего доустанавливать не нужно).
- Несколько ГБ свободного места на диске (файл состояния растёт по мере работы).
- Интернет без блокировки исходящих подключений на порты 2001 и 8092.

## Установка

1. Скачайте архив `viz-node-windows-<версия>.zip` из последнего релиза **Windows Build**: https://github.com/VIZ-Blockchain/viz-cpp-node/releases
2. Распакуйте его целиком в любую папку — внутри уже лежит всё нужное:

```
vizd.exe               нода
cli_wallet.exe         консольный кошелёк (не обязателен)
start-viz.bat          запуск ноды
open-forecaster.bat    открыть Forecaster с диска
open-wallet.bat        открыть VIZ Wallet с диска
data\config.ini        настройки ноды (правьте этот файл)
client\forecaster\     локальная копия Forecaster
client\wallet\         локальная копия VIZ Wallet
```

3. Запустите `start-viz.bat` двойным кликом.

При первом запуске рядом с `config.ini` появится всё состояние цепи. Нода найдёт доверенных пиров, скачает у них снапшот с проверкой контрольной суммы и продолжит синхронизацию с сети.

Когда в логе пойдут номера блоков — нода работает. Локальный API будет доступен по адресу `http://127.0.0.1:8090`.

## Как переключить клиенты на свою ноду

Запустите `open-forecaster.bat` или `open-wallet.bat` и в настройках выбора ноды укажите `http://127.0.0.1:8090` (в Forecaster для этого есть готовая кнопка «Моя нода»).

Важно открывать именно **локальные копии из папки `client`**, а не публичные версии в интернете. Браузеры запрещают странице, открытой по `https://`, обращаться к `127.0.0.1` — это отдельное разрешение Local Network Access, и запрос блокируется ещё до того, как уйдёт на ноду, так что настройками самой ноды это не обходится. Копия, открытая с диска, под запрет не попадает и с вашей нодой работает.

Публичные версии клиентов при этом никуда не деваются — просто они ходят на публичные ноды, а не на вашу.

## Безопасность

RPC намеренно слушает только `127.0.0.1` — то есть доступен исключительно с этого компьютера. У API нет аутентификации, а CORS открыт для любого источника, поэтому **не меняйте адрес на `0.0.0.0`**, если только вы осознанно не отдаёте ноду в свою локальную сеть и не понимаете последствий.

Приватные ключи нода не хранит и не требует: подписывают транзакции клиенты, нода их только принимает и рассылает.

## Тестнет вместо мейннета

Достаточно заменить в `data\config.ini` адреса пиров на тестнетовые (`p2p-seed-node` и `trusted-snapshot-peer`) и запустить ноду с пустой папкой данных. Сборка та же самая.

## История операций

Плагины `operation_history` / `account_history` включены, чтобы экраны истории в кошельке работали с вашей собственной ноды. Полная история всех аккаунтов — самая тяжёлая часть состояния, поэтому она ограничена скользящим окном: `history-count-blocks = 201600` — это неделя при блоке в 3 секунды, всё, что старше, вычищается по мере роста цепи. Нужен более длинный хвост — поднимите значение (30 дней = `864000`), нужен минимальный размер на диске — уберите обе строки `plugin = ...history`. Ставкам, ликвидности и рынкам Forecaster история операций не нужна в любом случае.

## Если что-то пошло не так

- **«vizd.exe not found»** — исполняемый файл должен лежать рядом с `start-viz.bat`.
- **Нода не находит пиров** — проверьте, что фаервол или антивирус не режет исходящие подключения `vizd.exe`.
- **Хочется начать с нуля** — остановите ноду и удалите папку `data`; следующий запуск скачает свежий снапшот.
